# 阿禾｜虚构示例角色

阿禾是本仓库用于测试个人 IP 流程的知识讲解人物，不是作者本人、真人复刻或用户的正式 IP。

## 固定身份

- 约三十岁的成年女性，略圆的长方脸，清晰眼睛和温和闭嘴微笑。
- 深棕色下巴长度波浪短发，角色右额侧扫卷发。
- 锈橙色圆框眼镜，透明镜片；无耳环或其他首饰。
- 青绿色无翻领拉链夹克，中央拉链，角色本人左胸一处竖拉链口袋，下方两侧斜插袋，袖口／下摆简洁。
- 象牙白直筒裤，深棕色系带低帮鞋，奶油色鞋底。
- 柔和哑光立体插画，约五点五头身；此为二维图片，不是 3D 模型。

初始提示仅指定胸部口袋，首张生成图还补全了下方两侧斜插袋；检查后将其纳入本示例的服装约定，多视图沿用。背部采用无装饰夹克和普通长裤结构，是本次设计补全，未依据真人照片。

## 配色建议

深棕发色、锈橙眼镜、灰青绿夹克、象牙白长裤、深棕鞋。用于文字指导的近似色可参考：夹克 `#526F6A`、眼镜 `#A34F27`、长裤 `#E9DCC6`、鞋 `#584235`。这些是设计建议，未声称图片像素准确匹配这些色值。

## 变化边界

可按内容调整动作、表情和场景。保持身份年龄感、脸型、短发轮廓、眼镜、服装结构、口袋侧别、鞋型和画风。不增加 Logo、首饰、手表或道具作为默认特征；需要换装时另存明确的新版本。

三视图从左到右：正面、角色左侧严格侧面（脸朝画面右）、背面。背面不出现正脸和前胸拉链；侧面被遮挡的胸部口袋不能依据不可见部位判断通过。
