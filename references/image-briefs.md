# 图像任务怎么写

这些是本项目的任务组织方式，不是某个模型的专用 API 参数。使用宿主已提供的生图／编辑工具，依其接口传入实际图片、透明背景参数等；不要求用户额外安装另一个 Skill。

## 正面预览

按这个顺序组合一份具体描述：用途 → 人物身份 → 固定服装／配件 → 画风与比例 → 构图 → 背景 → 必须避免。

例如，讲述者需要嘴眼清晰、轮廓简洁；头像要在缩小后仍能识别；三视图的前置预览要完整全身。不要为头像额外露出全身，也不要把输入照片中的看不见部位说成已经观察到。

参考图分别标记用途：人物身份参考、画风参考、编辑目标。已有角色只换画风时，固定脸型、发型、服装和配件；用户要求重新设计时才把明确指定的部分放开。

## 三视图

给工具附上选定的正面图，再写：

> 以输入人物图为同一身份的依据，制作角色设定用的三视图。横向排列三个完整全身人物：正面、角色左侧严格侧面、背面。保持头顶和脚底近似对齐、同一身高、同一头身比和自然站姿。侧面脸朝画面右侧，只显示单侧轮廓；背面不露正脸。严格保留本次角色约定中的发型、脸型、衣服结构、颜色和配件。用干净浅色背景；不添加标签、道具、Logo、额外角色或装饰。隐藏于视角后的部件不强行露出。

需要补全参考图看不见的背面结构时，采用最简单、与正面服装相容的设计，记为“本次补全”。不要在背面添加新口袋／徽章当作装饰。

## 透明人物图

附上同一人物参考，明确：

> 输出单个人物透明 PNG，完整头脚及少量透明边距。保留人物身份、服装、体型、画风和姿势，只移除背景；头发细节、眼镜及衣服不要被背景处理误删。不加地面、阴影底板、白边、棋盘格或文字。

同时启用工具的透明输出参数。如果工具不支持透明输出，就交付其真实能力范围内的图片并说明缺项；不得把提示词里“透明”二字当成检测结果。

## 定点修正

列出“改什么”及“保持什么”，以实际出错图片为编辑目标，并附身份图。例如：只把第三个视角改为背面，其他两个视角及所有衣服特征保持。修正后重新看整张图，不能认为局部编辑天然不会影响其他区域。

提示词记录中保留实际提交内容和实际参考文件的包内相对路径；没传图片时记录空参考，不得补写不存在的图像输入。
